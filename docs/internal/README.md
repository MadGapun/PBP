# Interne Arbeitsdokumente

Dieser Ordner enthält Arbeitsstände aus der Entwicklung von PBP:
Analysen, Audits, Handoff-Dokumente zwischen den beteiligten
KI-Assistenten, Release-Readiness-Prüfungen und historische
Planungsdokumente. Sie werden aus Transparenz aufbewahrt, sind aber
**nicht die Nutzerdokumentation** und beschreiben teils überholte
Stände.

Die Nutzerdokumentation findest du hier:

- [Wiki](https://github.com/MadGapun/PBP/wiki) — Installation, erste Schritte, alle Funktionen
- [docs/FAQ.md](../FAQ.md) — häufige Fragen
- [docs/DOKUMENTATION.md](../DOKUMENTATION.md) — technischer Überblick
- [docs/architecture.md](../architecture.md) — Architektur
- [docs/ROADMAP.md](../ROADMAP.md) — Roadmap
